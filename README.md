# 墨鍵寫作（InkKey Writer）

## 核心設計：零干擾的形碼自然書寫體驗

**墨鍵寫作** 移除所有遊戲關卡、計分與外部連線干擾，讓形碼寫作者能在任何桌面或行動裝置瀏覽器中，直接以靈明形碼沉浸寫作：

1. **底線焦點與景深淡化（Focal Baseline & Depth Fade）**：書寫焦點始終穩定鎖定於視窗中下部微光細線之上；已寫成的上方段落隨行距自然淡出景深，讓目光純粹聚焦當下一字。
2. **極簡純盲打（無底部選字列）**：不設傳統輸入法選字框；輸入緩衝與目標字根隨指法演化於焦點原位顯現，頂部與底部控制列於落筆後自動隱去。
3. **雙螺旋機率演化雲圖（Evolving Dual-Spiral Cloud）**：
   - **字根優先演化**：書寫區域優先呈現當前鍵位主根與全碼結構演進路徑，隨指法擊鍵平滑過渡，避免簡碼詞搶先跳出打斷手感。
   - **逆時針字根螺旋 ＆ 順時針簡碼螺旋**：剩餘字根與全碼結構候選沿**逆時針方向向上螺旋展開**；對應簡碼詞則沿**順時針方向向下螺旋分佈**，各以細微墨絲牽引，互不混雜。
   - **空白鍵激發簡碼／選字**：所有簡碼詞皆不強行自動上屏，按下 `Space` 即可直接取代目標書寫格完成上屏。
   - **墨跡暈染 ＆ 宮殿切換**：支援切換「機率演化」或「宮殿原圖」，並可於設定中細調「背景干擾度」與「墨跡暈染（背景融合度）」；不需提示時亦可一鍵關閉雲圖。
4. **玄墨 ＆ 宣紙水墨雙意境**：提供深沉護眼的「玄墨（Night）」與仿宣紙纖維滲墨質感的「宣紙水墨（Wash）」，並同步支援「繁簡全集 / 僅繁體 / 僅簡體」字集切換。
5. **手機 26 鍵宮殿寫作 ＆ 記憶宮殿圖譜**：內建行動端 26 鍵宮殿觸控鍵盤（支援滑動／點按與物理鍵盤無縫並用），並保留全盤「記憶宮殿」圖譜供隨時查閱各鍵筆畫脈絡。

## 本機手稿管理與離線隱私

- **100% 純前端靜態執行**：無後端伺服器、無登入帳號、無任何數據遙測；全部文稿僅保存於瀏覽器本地 `localStorage`。
- **多篇手稿與一鍵匯出**：支援新建／切換多篇本地草稿、即時字數統計，並可一鍵複製全文或匯出 `.md` / `.txt` 純文字檔案。

## 操作與快捷鍵一覽

| 按鍵 | 功能說明 |
| :--- | :--- |
| `A–Y` | 輸入靈明字根鍵位（首鍵顯示主根，續鍵沿結構路徑演進；僅 3–4 鍵唯一全碼自動成字） |
| `Space` | 激發當前目標／簡碼詞取代書寫格並上屏；緩衝為空時輸入空白 |
| `Tab` / `←` `→` | 緩衝輸入期間於候選間無聲切換預覽 |
| `Backspace` | 退回上一個緩衝鍵位；緩衝為空時刪除游標前一字 |
| `Esc` | 清空當前未上屏緩衝或收合設定面板 |
| `Enter` | 緩衝為空時換行；緩衝未空時送出原始字母 |
| `Ctrl` / `Cmd + Space` | 快速切換「靈明形碼」與「英文直出」模式 |
| `Ctrl` / `Cmd + Z` / `Y` | 復原（Undo）與重做（Redo） |

## 本地開發與建置

> 建議環境：Node.js 20.19+ 或 22 LTS

```bash
# 1. 安裝相依套件
npm install

# 2. 啟動本地開發伺服器（Port 3000）
npm run dev

# 3. 執行 TypeScript 型別檢查與正式建置
npm run lint
npm run build
```

建置完成後的靜態網站輸出至 `dist/` 目錄，可執行 `npm run preview` 於本地預覽正式版。

## 部署至 GitHub Pages

本專案已預先設定好 `vite.config.ts` 的相對路徑（`base: './'`）與 GitHub Actions 自動部署腳本（`.github/workflows/deploy.yml`）：

1. 將專案推送至 GitHub 倉庫（例如 `lvxiaoc/mos` 的 `main` 分支）。
2. 前往倉庫 **Settings** → **Pages**，將 **Source** 設為 **GitHub Actions**。
3. 等待 **Actions → Deploy to GitHub Pages** 顯示完成後，即可透過 `https://<你的GitHub帳號>.github.io/<倉庫名稱>/` 直接開啟使用。
